Font and Unicode lookup table notices

rust/glossapi_rs_pdfrepair/fixtures/font_tables.json is generated by
generate_font_tables.py from FontTools lookup tables and Python Unicode
properties. The static tables are embedded in the native extension.

Sources:
- FontTools 4.68.0 (standard glyph order and CFF lookup tables):
  https://github.com/fonttools/fonttools
- Adobe AGL/AGLFN, upstream revision
  4036a9ca80a62f64f9de4f7321a9a045ad0ecfd6, as retained by fontTools.agl:
  https://github.com/adobe-type-tools/agl-aglfn
- Unicode 14.0.0 character properties via Python 3.11 unicodedata:
  https://www.unicode.org/Public/14.0.0/ucd/ReadMe.txt
