# Bundled data and fixture notices

GlossAPI's EUPL-1.2 licence does not replace the licences of independent third-party data.
The following notices and source identities are shipped with the wordlists in
`src/glossapi/data/wordlists/` (also included in installed wheels and source distributions).

| Data | Distribution terms | Included notice / provenance |
| --- | --- | --- |
| Hunspell el_GR 0.9, `el_GR.dic.gz` | MPL-1.1 option of the upstream MPL/GPL/LGPL alternatives | `LICENSE.el_GR`, `MPL-1.1.txt`, `README.md`; unmodified UTF-8 source, only reproducible gzip compression |
| SCOWL en_US 2020.12.07, `en_US.dic.gz` | MIT **and** BSD component terms | `LICENSE.en_US`, `README.md`; complete component notices and permissions retained |
| Moby Language II German, Spanish, French and Italian surface vocabularies | Public-domain grant by Grady Ward, January 2001 | `LICENSE.moby`, `moby_manifest.json`, `README.md`; original/derived hashes and normalization described |
| OWN-PT Portuguese lemmas | CC BY 4.0 | `LICENSE.pt`, `moby_manifest.json`; attribution, pinned source, transformations retained |
| Portuguese `stopwords-pt` function words | MIT | `LICENSE.pt`; notice retained alongside the combined Portuguese vocabulary |

These are offline routing vocabularies, not spell-correction services or OCR ground truth.
The Greek list is the default v4 image-page vocabulary; v5/v6 Latin validity is opt-in.

## Fixtures

- `tests/layout_v2_ref/` contains this project's frozen Python label/geometry reference and synthetic fuzz
  generators, under EUPL-1.2. The real-page character tables and source PDFs used by the external exactness
  campaign are not bundled. Their local verification does not grant rights to redistribute source documents.
- `rust/glossapi_rs_pdfrepair/fixtures/layout_selftest.pdf` contains the synthetic `Ab 1.` / `Cd` text generated
  by `generate_layout_selftest.py`. Font-repair review PDFs and TrueType fixtures are generated by the adjacent
  builders from simple synthetic glyphs; they do not copy external font binaries. These project fixtures use EUPL-1.2.
- `tests/fixtures/k5d_no_text/` contains synthetic byte-level PDF/parser cases generated by `make_fixtures.py`;
  they contain no owner scans or real document pages and use EUPL-1.2.
- `tests/fixtures/greekocr/polytonic_scan.pdf` is a synthetic image-only rendering of Homer, *Iliad* 1.1–6
  (ancient Greek original, public domain). `source.json` identifies the transcription and rendering. The local
  authoring script uses a system Times New Roman font; no font binary is embedded or redistributed in the fixture.
  The surrounding project scripts/receipts use EUPL-1.2. Observed OCR output is a regression baseline, not ground truth.
- `samples/lightweight_pdf_corpus/` contains the project's small synthetic extraction examples and expected outputs.

The historical Greek variety classification CSV is retained from upstream with the repository EUPL notice; no separate dataset licence or provenance notice has been located.
This release adds no licence grant for external PDFs used during local/public-data verification.

## Compiled lookup tables

`rust/glossapi_rs_pdfrepair/fixtures/font_tables.json` embeds Adobe AGL/AGLFN glyph mappings
and standard post/CFF lookup tables from FontTools, plus Greek character membership generated
from Python's Unicode properties. `FONT_TABLES_LICENSES.txt` preserves the Adobe BSD-3-Clause,
FontTools MIT and Unicode data notices and provenance. This file ships as a licence file in
both the sdist and wheel; these independent table terms are not replaced by EUPL.
